# Shourya Saxena — Portfolio

Interactive personal portfolio built on a procedural Three.js botanical valley (originally the "Fernhollow" engine).

Stack: Vite · React 19 · TypeScript · Three.js (custom GLSL, instanced rendering, post-processing) · Tailwind CSS v4 · Motion.

```bash
npm install
npm run dev        # http://127.0.0.1:3000
npm run build      # typecheck + production build to dist/
npm run preview    # serve dist/ on :4173
```

No API keys or server are required. Deploys as a static site (Vercel).
